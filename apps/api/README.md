# @ad6/api — Enterprise HSE Express 5 Gateway

Handles multi-tenant statutory compliance, Gemini AI proxy, WebSocket events, and REST endpoints for incidents, permits, CAPAs, and audits.

## Endpoints
- `/api/v1/incidents`: Incident management & statutory dispatch.
- `/api/v1/permits`: PTW authorization with SoD enforcement.
- `/api/v1/capas`: Remediation action register with SLA timers.
- `/api/v1/statutory/form-g`: Oman Ministry of Labour Form G notification adapter.
- `/api/gemini/*`: Server-side proxied AI intelligence.
